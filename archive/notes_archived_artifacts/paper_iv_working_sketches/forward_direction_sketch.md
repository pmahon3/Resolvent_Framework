# Forward Direction: ε-Injectivity → L²-Approximation Rate

**Status:** Mathematical sketch. Attempting to make rigorous.
**Date:** 2026-04-05

---

## Setup

Fix:
- (X, ℬ, μ, T): probability space with μ-preserving T
- h ∈ L∞(X, μ) ∩ Hölder(s, C_h): observation function, s-Hölder with constant C_h
- L ∈ ℕ: lag depth
- n ∈ ℕ: sample size
- x₁, …, xₙ: observations (for now: i.i.d. from μ; ergodic case later)

**The delay feature map:**

Φ_h^(L) : X → ℝ^(L+1),   Φ_h^(L)(x) = (h(x), h(Tx), …, h(T^L x))

**The delay algebra at lag L:**

𝒜_h^(L) = alg{h ∘ Tᵏ : k = 0, …, L} ⊆ L∞(X, μ)

Polynomials in the components of Φ_h^(L). Equivalently: all functions of the
form p(Φ_h^(L)(x)) for polynomials p : ℝ^(L+1) → ℝ.

**The empirical projection:**

For f ∈ L²(μ), the empirical L²(μ_n)-projection of f onto 𝒜_h^(L) is:

f̂_n^(L) = argmin_{g ∈ 𝒜_h^(L)} (1/n) Σᵢ (f(xᵢ) - g(xᵢ))²

This is exactly the nonparametric regression of f(xᵢ) on features Φ_h^(L)(xᵢ).

**The quantity we want to bound:**

‖f - f̂_n^(L)‖²_{L²(μ)} = ∫ (f(x) - f̂_n^(L)(x))² dμ(x)

---

## The key decomposition

Standard bias-variance for regression:

‖f - f̂_n^(L)‖²_{L²(μ)} ≤ 2 · bias²(f, L) + 2 · variance(n, L)

where:

**Bias term:** How well can f be approximated by *any* function in 𝒜_h^(L)?

bias(f, L) = inf_{g ∈ 𝒜_h^(L)} ‖f - g‖_{L²(μ)}

**Variance term:** Statistical error from estimating the best approximation
from n samples.

variance(n, L) ≈ dim(𝒜_h^(L)) / n  (for a parametric class)

The variance term is manageable — it's O((L+1)^deg / n) for degree-deg
polynomials. The hard part is the **bias term**.

---

## The bias term: where ε-injectivity enters

The bias term asks: how well can an arbitrary f ∈ Hölder(s) be approximated
by functions of Φ_h^(L)?

**Reformulation:** f is approximable by 𝒜_h^(L) iff f is "nearly measurable"
with respect to the σ-algebra generated by Φ_h^(L), i.e., iff f is nearly
constant on the level sets of Φ_h^(L).

Two regimes:

**Regime 1 — Φ_h^(L) is injective (reconstruction holds):**

If Φ_h^(L) is injective (in the a.e. sense), then σ(Φ_h^(L)) = ℬ mod μ
(this is the reconstruction theorem, Paper III). In this case, every
f ∈ L²(μ) can be written as f = f̃ ∘ Φ_h^(L) for some Borel f̃, so
bias(f, L) = 0 (in the limit of polynomial degree → ∞ by Stone-Weierstrass).

**Regime 2 — Φ_h^(L) is ε-injective (approximate reconstruction):**

Φ_h^(L) is ε-injective if for μ ⊗ μ-almost every pair (x, x'):

Φ_h^(L)(x) = Φ_h^(L)(x')  ⟹  |f(x) - f(x')| ≤ ε · ‖f‖_{Hölder(s)}

This says: points that look the same to the delay map have f-values within ε.

Under ε-injectivity, every Hölder(s) function f satisfies:

|f(x) - f(x')| ≤ C · (‖Φ_h^(L)(x) - Φ_h^(L)(x')‖^α + ε)

for some α > 0 depending on s and the Hölder constants of h and T.

**This is the key claim to make rigorous.** It says: if the delay map nearly
separates points (ε-injective), then Hölder functions are nearly constant
on the ε-level sets of the delay map.

---

## Attempt at the bias bound

**Assumption (ε-injectivity):** There exists ε > 0 such that for μ⊗μ-a.e. (x,x'):

‖Φ_h^(L)(x) - Φ_h^(L)(x')‖ ≤ δ  ⟹  |f(x) - f(x')| ≤ ε + C·δ^β

for some β > 0 (to be determined in terms of s, the Hölder exponent of f,
and the regularity of h and T).

**Consequence for bias:** For any function g(x) = g̃(Φ_h^(L)(x)), the
best such g̃ (in L²) can approximate f up to the error on level sets:

‖f - g‖²_{L²(μ)} ≤ ∫∫ |f(x) - f(x')|² dμ(x) dμ(x') [over pairs with same Φ_h^(L) value]
                  ≤ (ε + C·δ^β)² · μ⊗μ({pairs within δ in delay space})

Taking δ → 0 in the right way: if we use a g̃ that is locally constant at
scale δ in ℝ^(L+1), then on each δ-ball in delay space the approximation
error is at most (ε + C·δ^β)², and the number of δ-balls needed to cover
the image Φ_h^(L)(X) ⊆ ℝ^(L+1) is at most (diam/δ)^(L+1).

This gives a bias bound of the form:

bias²(f, L) ≤ C · (ε² + δ^{2β})

for any δ > 0, with an implicit constraint from the covering.

**The issue:** This bound depends on ε (the injectivity deficit) but NOT
on L or n yet. The L and n dependence enters through:
1. How ε depends on L: as L increases, Φ_h^(L) becomes more injective
   (more delays = finer separation), so ε = ε(L) → 0 as L → ∞.
2. How the variance term scales with L.

---

## How ε depends on L: the orbit separation rate

This is where the dynamics T enters crucially.

For the theoretical map Φ_h : X → ℝ^ℕ (all lags), reconstruction holds iff
𝒪_h = ℬ mod μ. For the truncated map Φ_h^(L), the separation improves with L.

**Quantifying orbit separation:**

Define the L-separation defect:

ε(L) = μ⊗μ({(x,x') : Φ_h^(L)(x) = Φ_h^(L)(x'), x ≠ x'})

= "probability that two distinct points have the same L-lag delay vector"

Under the reconstruction condition (𝒪_h = ℬ mod μ), ε(L) → 0 as L → ∞.
The *rate* at which ε(L) → 0 depends on the dynamics T and observation h.

**Three cases:**

**Case 1 — Finite separation:** ∃ L₀ such that Φ_h^(L₀) is a.e. injective.
Then ε(L) = 0 for L ≥ L₀. This is the Takens regime: L₀ = 2d+1 for
generic h on a d-manifold.

**Case 2 — Exponential separation:** ε(L) ≤ C · e^{-λL} for some λ > 0.
This holds when T is exponentially mixing and h has sufficient variation.
λ is the Lyapunov exponent or mixing rate.

**Case 3 — Polynomial separation:** ε(L) ≤ C · L^{-α} for some α > 0.
This holds for polynomially mixing systems (e.g. intermittent maps).

The rate of the finite-sample density bridge will depend on which case
applies — this is where the dynamical properties of T enter the rates.

---

## Putting it together: the forward rate

Combining bias and variance, and using ε(L) for the separation defect:

**Bias:** bias²(f, L) ≤ C₁ · ε(L)²

(from the ε-injectivity bound above, taking δ → 0)

**Variance:** variance(n, L) ≤ C₂ · (L+1)^{deg} / n

(dimension of degree-deg polynomials in L+1 variables; use deg = ⌈s⌉)

**Total error:**

‖f - f̂_n^(L)‖²_{L²(μ)} ≤ C₁ · ε(L)² + C₂ · L^s / n

**Optimal L:** Balance bias and variance by choosing L = L(n) to minimise
the sum. For exponential case (ε(L) ~ e^{-λL}):

L(n) ~ (1/λ) log n   ⟹   rate ~ (log n)^s / n

For polynomial case (ε(L) ~ L^{-α}):

L(n) ~ n^{1/(2α+s)}   ⟹   rate ~ n^{-2α/(2α+s)}

**Observation:** The rate depends on the dynamics T through α (or λ).
This is the natural entry point for the dynamical properties of T into
the estimation problem — not assumed as a separate parameter but derived
from the orbit structure.

## What needs to be made rigorous

1. **The ε-injectivity → Hölder-approximation step:**
   The claim "|f(x) - f(x')| ≤ ε + C·δ^β when ‖Φ_h^(L)(x) - Φ_h^(L)(x')‖ ≤ δ"
   needs a precise statement. It requires:
   - A regularity assumption on h (Hölder(s) with constant C_h)
   - A regularity assumption on T (or its iterates T^k)
   - An assumption on f (Hölder(s') for some s')
   The exponent β should be expressible in terms of s, s', C_h, regularity of T.

2. **The bias bound via covering:**
   The step from ε-injectivity to bias²(f,L) ≤ C·ε(L)² uses a covering
   argument on the image Φ_h^(L)(X). This needs:
   - A bound on the covering number of Φ_h^(L)(X) ⊆ ℝ^(L+1)
   - This is controlled by the metric entropy of X under the delay metric
     d_L(x,x') = ‖Φ_h^(L)(x) - Φ_h^(L)(x')‖

3. **The variance bound:**
   The claim variance ≤ C·L^s/n uses a VC-dimension or Rademacher bound
   for the polynomial class of degree ⌈s⌉ in L+1 variables.
   VC dimension of degree-d polynomials in m variables ≈ O(m^d).
   So variance ≤ C·(L+1)^s/n. This is standard but needs citation.

4. **The orbit separation rate ε(L):**
   This is the most dynamical part. For specific systems (e.g. Anosov
   diffeomorphisms, expanding maps) ε(L) ~ e^{-λL} can be derived from
   the mixing rate. For general T, ε(L) is a property of T and h that
   needs to be stated as an assumption.

## The key open question at this stage

Is item 1 above true? Specifically:

> If h ∈ Hölder(s) and T is Lipschitz (with constant κ), does
> ‖Φ_h^(L)(x) - Φ_h^(L)(x')‖ ≤ δ imply |h(x) - h(x')| ≤ C · δ^β
> for some β = β(s, κ, L) > 0?

**Attempt:**

‖Φ_h^(L)(x) - Φ_h^(L)(x')‖² = Σ_{k=0}^{L} |h(T^k x) - h(T^k x')|²

Each term: |h(T^k x) - h(T^k x')| ≤ C_h · d(T^k x, T^k x')^s
                                    ≤ C_h · κ^{ks} · d(x, x')^s

So ‖Φ_h^(L)(x) - Φ_h^(L)(x')‖ ≥ |h(x) - h(x')| (just the k=0 term)

This gives the **wrong direction**: the delay norm controls d(x,x') from
above, not f(x) - f(x') from above.

We need the reverse: small delay norm → small |f(x) - f(x')|.

**This is only possible if Φ_h^(L) separates x from x'** — i.e., if
there exists some k ∈ {0,…,L} such that h(T^k x) ≠ h(T^k x') when x ≠ x'.

If Φ_h^(L) is ε-injective, then for "most" pairs (x,x'), there exists k
such that |h(T^k x) - h(T^k x')| ≥ ε' > 0. But this doesn't directly
bound |f(x) - f(x')| for an arbitrary f.

**Conclusion:** The ε-injectivity of Φ_h^(L) does NOT directly imply that
Hölder functions have small variation on level sets of Φ_h^(L), unless
we impose additional conditions on f (e.g. f is measurable w.r.t. 𝒪_h^(L)).

**This is a genuine obstruction.** It suggests the forward direction as
stated may be false in general, or requires a different formulation.

---

## Reformulation forced by the obstruction

The obstruction reveals something important: ε-injectivity of Φ_h^(L)
controls the **geometry of X in delay-coordinate space**, but it does NOT
directly control how well *arbitrary* Hölder functions can be approximated
by functions of Φ_h^(L).

The correct statement is more restricted:

> Functions f that are *already measurable w.r.t. 𝒪_h* (i.e., f = g ∘ Φ_h
> for some Borel g) are well-approximated by 𝒜_h^(n,L) if Φ_h^(L) is
> ε-injective and g is Hölder.

For arbitrary f ∈ Hölder(s), ε-injectivity alone is insufficient.

**What IS controlled by ε-injectivity:**

The projection of f onto 𝒜_h^(L) in L²(μ) — i.e. the conditional
expectation E[f | 𝒪_h^(L)] — is well-approximated empirically. But the
*bias* (the distance from f to 𝒪_h^(L)) is controlled not by ε-injectivity
but by how close 𝒪_h^(L) is to ℬ.

**The correct forward direction is therefore:**

> If 𝒪_h^(L) approximates ℬ (in the sense that μ(s △ E_s) ≤ δ for
> every s ∈ ℬ and some E_s ∈ 𝒪_h^(L)), then the empirical projection
> of any f ∈ L²(μ) onto 𝒜_h^(n,L) is close to f in L²(μ).

And the connection to ε-injectivity of Φ_h^(L) needs to go through the
reconstruction theorem (Paper III): ε-injectivity of Φ_h^(L) implies that
𝒪_h^(L) approximates ℬ well, via the density bridge.

**But this is circular:** we are using the density bridge to prove the
finite-sample density bridge. The correct route is:

1. Take "𝒪_h^(L) approximates ℬ" (the σ-algebra approximation condition)
   as the *primary* assumption, not ε-injectivity.
2. Derive the L²-approximation rate from this condition directly.
3. Then separately ask: when does ε-injectivity of Φ_h^(L) imply
   σ-algebra approximation? This is the *theoretical* content of Paper III,
   not a finite-sample statement.

---

## Revised formulation of the forward direction

**What we can actually prove (tentative):**

Let δ(L) = sup_{s ∈ ℬ} inf_{E ∈ 𝒪_h^(L)} μ(s △ E) be the σ-algebra
approximation error at lag L.

**Claim:** For f ∈ L²(μ) with ‖f‖_{L²} ≤ 1:

‖f - E[f | 𝒪_h^(L)]‖_{L²(μ)} ≤ C · δ(L)^{1/2}

and the empirical estimate of E[f | 𝒪_h^(L)] satisfies:

‖f - f̂_n^(L)‖_{L²(μ)} ≤ C · δ(L)^{1/2} + C' · (dim 𝒜_h^(L) / n)^{1/2}

where the first term is the bias (controlled by σ-algebra approximation)
and the second is the variance (controlled by sample size and lag depth).

**This is the natural statement.** It connects:
- δ(L): how well 𝒪_h^(L) approximates ℬ (the σ-algebra side)
- L²-approximation error (the analytic side)
- n: sample size (statistical term)

The connection to ε-injectivity is then: ε-injectivity of Φ_h^(L) is a
*sufficient condition* for δ(L) to be small (via Paper III), not a direct
condition on L²-approximation.

## Status

The forward direction sketch has revealed that:

1. **ε-injectivity alone is insufficient** for L²-approximation of arbitrary
   Hölder functions — the obstruction is real.

2. **The correct primary condition is σ-algebra approximation** δ(L) → 0,
   which is the finite-sample analogue of 𝒪_h = ℬ mod μ.

3. **The forward direction then says:** δ(L) → 0 implies L²-approximation
   error → 0, with explicit rates involving δ(L) and n.

4. **The connection to ε-injectivity** runs through Paper III's reconstruction
   theorem: ε-injectivity → δ(L) → 0 (this is the theoretical content).

5. **The finite-sample density bridge is therefore:**
   - *Bias bound:* ‖f - E[f|𝒪_h^(L)]‖ ≤ C·δ(L)^{1/2}
   - *Statistical bound:* ‖f̂_n^(L) - E[f|𝒪_h^(L)]‖ ≤ C'·(L^s/n)^{1/2}
   - Combined: ‖f - f̂_n^(L)‖ ≤ C·δ(L)^{1/2} + C'·(L^s/n)^{1/2}

6. **Open:** Is item 5 actually true? The bias bound is the key claim.
   It should follow from standard conditional expectation theory (the
   projection onto a sub-σ-algebra minimises L² distance). The statistical
   bound is standard nonparametric regression. What needs work is the
   *rate* for δ(L) → 0 in terms of dynamics.

## Next concrete step

Prove or disprove: **‖f - E[f | 𝒪_h^(L)]‖_{L²(μ)} ≤ C · δ(L)^{1/2}**

This should be a consequence of the fact that E[f | 𝒪_h^(L)] is the
L²(μ)-projection of f onto L²(X, 𝒪_h^(L), μ), plus a bound on how
far L²(X, 𝒪_h^(L), μ) is from L²(X, ℬ, μ) in terms of δ(L).

The natural tool is: for any f ∈ L²(μ),

‖f - E[f | 𝒪_h^(L)]‖²_{L²(μ)} = ‖f‖² - ‖E[f|𝒪_h^(L)]‖²

and the gap ‖f‖² - ‖E[f|𝒪_h^(L)]‖² should be controlled by δ(L).

**Is this true?** Need to think about it. It's not obvious — δ(L) is a
supremum over all sets s ∈ ℬ, and the gap in the above involves the
*specific* function f. The bound should depend on f through ‖f‖_{L²} only
(universal over f in the unit ball), or through Hölder norms (for smoother f).

This is the crux. Work through it in the next session.

No other file was edited and nothing was committed.*

**Verdict: CONFIRMED, with a sharpening.**
- **Reversal.** The named open checkpoint of D-DIL-1 (Navara's 𝓛_ℕ with the extension of a
  free-ultrafilter state) is **not open**. That state dilates, and so does **every** state on 𝓛_ℕ.

## 1. D exactly as posed

`docs/dilation_question_scoping.md:14–21` defines D(P): for **every finitely additive state** m on
the OMP P, there exist
- an OMP embedding φ: P ↪ Q,
- a σ-orthocomplete OMP Q,
- and a σ-additive state s on Q,

with m = s∘φ. By l.23–27, φ need **not** preserve countable joins.

"Embedding" is fixed at `docs/regularity_sigma_additivity_pullback.md:12–19`: injective, preserves
′, and preserves finite orthogonal joins (hence 0, 1 and order). Regularity is not required.

The ledger restates the same question at `docs/site_regularity_prediction_ledger.md:246–249`:
"for which OMPs P is every finitely additive state m a pullback". It lists positive regimes at
l.267–271, the named checkpoint at l.273–278, and the status OPEN — ADJACENT — PARKED at l.280–282
(also l.10).

So D is quantified over **all** finitely additive states, with Q **existentially** chosen and no
constraint tying Q to P.

## 2. The two-valued claim (T8, `join_choice_as_object_scoping.md:205`)

**Construction.** Let P be σ-orthocomplete and m a two-valued state. Put
- Q = 2 × P,
- φ(a) = (m(a), a),
- s = π₁.

**Checks** ⟦HAND⟧:
- Q is an OMP and σ-orthocomplete, coordinatewise.
- φ(a′) = (1−m(a), a′) = φ(a)′.
- If a ⊥ b, then m(a) and m(b) are not both 1, so (m(a), a) ⊥ (m(b), b). Also
  m(a∨b) = m(a)+m(b) = m(a)∨m(b), so φ(a∨b) = φ(a)∨φ(b).
- φ is injective through the second coordinate. It also *reflects* order, so it survives stricter
  definitions of embedding.
- s(1) = 1. In a countable orthogonal family of Q, at most one first coordinate is 1, and joins are
  coordinatewise, so s is σ-additive.
- s∘φ = m.

**Lemma R sanity check.** If ⋁xₙ = a in P and m(a) = 1 while every m(xₙ) = 0, then
⋁φ(xₙ) = (0, a) ≠ φ(a). The gap (1, 0) has s-mass 1, which is the defect, as Lemma R requires.

**Is this what D asks?** Yes, to the letter. D allows any Q and any embedding, and imposes no
σ-regularity, minimality or generation condition. The construction is trivial *because* D is weak
here:
- the second coordinate supplies injectivity;
- P's own σ-orthocompleteness supplies Q's;
- the state lives entirely on a factor that ignores P.

That is a property of the question as posed, not a flaw in T8. If D was meant to ask for more (for
example, Q generated by φ(P)), the doc must say so; as written it does not. **Status: correct;
almost certainly folklore, so not to be claimed.**

Minor point on T8's second construction, φ_St into 𝒫(St₂) with s = δ_m. Under the repo's
definition, injectivity needs only that St₂ is separating. φ_St reflects order only if St₂ is
order-determining. This does not affect anything above.

## 3. The checkpoint on Navara's 𝓛_ℕ (primary source: `navara_1992.pdf`, pp. 427–428, read in full)

**Source facts.**
- 𝒱 = 𝒯 × 𝒮, with 𝒯 = {0,1} and 𝒮 finite and stateless. 𝒱 has exactly one state, which is 1 on
  everything ≥ u = (1, 0_𝒮).
- W is the horizontal sum of copies 𝒱_C (C ⊆ M, M countable).
- 𝓛 ⊆ W^M is the set of f with this property: if f(m) ∈ 𝒱_C∖{0,1}, then m ∈ C and f is constant
  on C.
- Navara proves that 𝓛 is closed under ′ and countable orthogonal joins **in W^M**, so these
  operations are coordinatewise.
- Elements have the form ⋁_{C∈𝒥} v_C|C, with 𝒥 a disjoint family of subsets of M.
- Navara states, without proof, that every state on {1|C} ≅ 𝒫(M) extends uniquely.
- The paper does **not** state that the extension of a two-valued state is two-valued, nor give a
  formula for it. That step needed checking.

**Disjointness of the C's** ⟦HAND⟧. If m ∈ C ∩ C′, then f(m) is a nontrivial element of both
𝒱_C and 𝒱_{C′}. Copies in a horizontal sum share only 0 and 1, so this is impossible.

**Projection morphism** ⟦HAND⟧. Let h: W → 2 be the first-coordinate projection on each block. It
is consistent because the blocks share only 0 and 1, and orthogonal pairs lie in a common block.
Then ψ(f) := E_f = {m : h(f(m)) = 1} is an OMP morphism 𝓛 → 𝒫(M), since the operations are
coordinatewise. It even preserves countable orthogonal joins.

**Formula ω(f) = μ(E_f), with μ(C) := ω(1|C)** ⟦HAND⟧.
1. *Residues are null.* Take r = ⋁_{C∈𝒦}(0, s_C)|C, where the s_C may vary. Then r ≤ z :=
   ⋁_{C∈𝒦}(0, 1_𝒮)|C, and z ∈ 𝓛 because 𝒦 is a countable disjoint family. The map
   g: 𝒮 → [0, z], s ↦ ⋁(0, s)|C, is an OMP morphism: the relative complement in 𝓛 is coordinatewise,
   since b∧a′ = (a∨b′)′ with a ⊥ b′. If ω(z) > 0, then ω∘g/ω(z) is a state on 𝒮, which is
   impossible. So ω(z) = 0, and hence ω(r) = 0. (The flag's version used a constant s; domination
   by z closes the varying-s case.)
2. *Split by support.* Let A = E_f. It is a union of members of 𝒥, so f = f_A ⊕ f_{A^c} with both
   parts in 𝓛. f_{A^c} is a residue, so ω(f_{A^c}) = 0. Also f_A ≤ 1|A, and 1|A ∧ f_A′ is a residue,
   so ω(f_A) = ω(1|A) = μ(A).
3. Every step uses only finite additivity. Each countable join is a single element of 𝓛.

**Consequence.** Every state on 𝓛 is μ∘ψ, with μ a finitely additive probability on 𝒫(M). This
matches Navara's "extends uniquely". If μ is a free ultrafilter, then ω is two-valued, so T8 alone
dilates it.

**All states dilate** ⟦HAND⟧. Put
- Q = Baire(βM) × 𝓛_ℕ, which is σ-orthocomplete,
- φ(f) = (Ê_f, f), where Ê is the clopen image of E_f,
- s = ν∘π₁, where ν is the Carathéodory extension of μ from the clopen algebra.

The clopen algebra carries a premeasure by the compactness argument, `dilation_question_scoping.md:122–131`.
Fremlin 416Q is not needed. Then s∘φ = μ∘ψ = ω. The embedding is not σ-regular: ⋁{n} = 1 in 𝓛,
while ⋃{n} = M ≠ βM. For a free μ the gap βM∖M carries all the mass, consistent with Lemma R.
**D(𝓛_ℕ) holds.**

## 4. Sharpening (general, ⟦HAND⟧)

Injectivity comes free from a second factor. So, for an OMP P that has a state, D(P) holds if and
only if both of these hold:
- (a) P embeds into some σ-orthocomplete OMP;
- (b) every state m = s₀∘ψ for some OMP **morphism** ψ, not necessarily injective, into a
  σ-orthocomplete Q₀ with σ-additive s₀.

For the converse direction, use (ψ, e) into Q₀ × Q₁.

**Corollary.** On a σ-orthocomplete P, D holds for every state in the weak* closed convex hull
cl conv St₂(P).
- Proof: m is the barycentre of a Radon probability ν on the compact set St₂. Take
  ψ(a) = {t : t(a) = 1}, which is clopen and hence Baire. Then m = ν∘ψ, and we use
  Q = Baire(St₂) × P.
- Conversely, any state that factors through a Boolean morphism lies in that hull.

Two-valued states (T8) and 𝓛_ℕ are special cases. What remains open:
- σ-orthocomplete P with states outside cl conv St₂ (e.g. Greechie-type logics with few or no
  two-valued states), unless a non-Boolean factorization exists, as in Bunce–Wright;
- non-σ-orthocomplete P, where (a) is Harding–Wang Problem 2.

This also overstates two passages of the scoping doc:
- `dilation_question_scoping.md:164–166` requires a *faithful* compact base, but only a morphism is
  needed;
- the concreteness flag at l.325–334 loses its force for σ-orthocomplete P, because faithfulness is
  not required.

        [Nonempty S.ι]

================================================================================
3. WHY THE ADDCONTENT ROUTE STOPS AT COUNTABLE EXTENSION
================================================================================

The cylGen_addContent construction assigns a finite measure to each element of
CylGen (single-query cylinders and their finite intersections). This finite layer
is fully algebraic and is complete.

The obstruction appears when one attempts to verify IsSigmaSubadditive: given a
countable disjoint sequence Cyl (i₀) (A₀), Cyl (i₁) (A₁), ... whose union is
again a single cylinder Cyl k B, one must simultaneously compress all cylinders
to a single common lower bound m in the index preorder. The existing
lowerBound_finset provides a lower bound for any finite collection of indices.
It does not provide one for the full countable sequence {i₀, i₁, i₂, ...},
because that set may be infinite and LowerDirected only asserts pairwise lower
bounds.

The consequence is structural: at the level of Outcome_m, the compression
argument that succeeds finitely — showing ⋃_finite Ec_n = Eu and applying ν m
additivity — cannot be executed for the countable union. The proof gets as far
as: "each finite partial union compresses correctly," but the passage to the
limit requires either a uniform lower bound for the entire sequence or a
different approach to the extension step.

================================================================================
4. THE MATHLIB THEOREM IDENTIFIED AND WHY IT DOES NOT APPLY
================================================================================

The theorem that would close Item 1, if applicable, is:

    MeasureTheory.isSigmaSubadditive_of_addContent_iUnion_eq_tsum
    (Mathlib.MeasureTheory.Measure.AddContent, line 674)

Its signature is:

    theorem isSigmaSubadditive_of_addContent_iUnion_eq_tsum
        {m : AddContent ℝ≥0∞ C} (hC : IsSetRing C)
        (m_iUnion : ∀ (f : ℕ → Set α) (_ : ∀ i, f i ∈ C) (_ : (⋃ i, f i) ∈ C)
          (_ : Pairwise (Disjoint on f)), m (⋃ i, f i) = ∑' i, m (f i)) :
        m.IsSigmaSubadditive

It derives IsSigmaSubadditive from σ-additivity (exact equality for countable
disjoint unions) under the hypothesis that C is a set ring — closed under binary
unions and differences.

CylGen is only a set semiring: it is closed under finite intersections and
differences (into finite disjoint unions of semiring elements), but it is not
closed under binary unions. A union of two distinct single-query cylinders
Cyl i A ∪ Cyl j B is generally not itself a single-query cylinder. Therefore
CylGen does not satisfy IsSetRing, and this Mathlib theorem cannot be applied.

Working in the ring closure supClosure CylGen would resolve the ring condition,
but would require redefining cylGen_addContent on the larger algebra and
re-running the well-definedness and additivity arguments there, which in turn
reintroduces the same countable lower-bound problem in the extension step.

================================================================================
5. THREE POSSIBLE NEXT DIRECTIONS
================================================================================

Direction A — Strengthen with a countable lower-bound hypothesis.

Add an ω-LowerDirected or DirectedComplete hypothesis to QuerySystem: every
countable directed subset of ι has a lower bound. Under this assumption,
lowerBound_finset generalizes to countable index sets, the σ-additivity argument
goes through directly, and isSigmaSubadditive_of_addContent_iUnion_eq_tsum
becomes applicable after passing to the ring closure. This is the cleanest
algebraic fix and makes the Lean theorem self-contained, but it adds a
hypothesis not currently in the note and restricts the theorem to well-founded
directed systems.

Direction B — Separate the finite premeasure theorem from the full extension
theorem in the manuscript.

The note currently states a single extension theorem. One could restructure it
to make explicit a two-level result: (i) a finite premeasure theorem (what is
now fully formalized — well-defined, finitely additive content on CylGen), and
(ii) a full extension theorem that explicitly lists an additional analytic
regularity condition. This matches the classical structure of the Kolmogorov
extension theorem, which distinguishes the algebraic consistency conditions
(finite-dimensional compatibility) from the analytic extension condition
(compactness of fibers or tightness). The Lean formalization would then be in
exact alignment with the manuscript at both levels.

Direction C — Pursue a different proof architecture closer to classical
Kolmogorov extension.

Rather than the semiring-to-measure route via AddContent, construct the measure
directly on Omega using the projective limit topology: equip each Outcome_i with
a topology making ν i Radon, use the inverse limit topology on Omega, and apply
the classical Prokhorov/Bochner extension theorem. Mathlib has some
infrastructure for Radon measures and weak convergence. This approach avoids the
countable lower-bound problem entirely — the analytic content is handled by
compactness rather than directedness — but requires topological hypotheses on
the query spaces and is a substantially different proof architecture from the
current purely measure-theoretic approach.

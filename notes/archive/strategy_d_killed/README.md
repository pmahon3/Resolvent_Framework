# Strategy D — killed material (archived 2026-06-19)

`problemset_strategy_d.{tex,pdf}` — the self-contained pen-and-paper kit for
**Strategy D** (*does a non-σ-complete, non-atomic, measure-free Boolean algebra
exist?*). Archived because **Strategy D was KILLED on prior-art 2026-06-18**
(`/audit full`): the math is true (the Argyros pre-Gleason algebra `Clop(Y,𝔗)` is
not σ-complete, hence a ZFC example) but it clears **no contribution bar** —
**Gaifman 1964** (PJM 14(1):61–73, Thm 2.2 + property (†)) already inhabits the ZFC
cell, *stronger* (atomless BA with no strictly-positive *finitely*-additive measure);
the non-σ-complete + atomless legs are trivial; the only hard ingredient
(measure-freeness) is Argyros's published theorem; and "Strategy D" was this
programme's *private* name, never a field-open problem.

The kit presents the problem as **open**, with a "live entry point" and sub-tasks —
which is now actively misleading, hence the move out of the live working layer.

# Boolean-factoring of the σ-essential contextual state — PARKED (Phase-2 audit)

*Seed proposed and audited 2026-06-23 (Session 13). PARKED: the primary Type-5 claim
FAILED the Phase-2 audit on a primary-source kill; the surviving Type-6 fragment is a
narrow corrected open-question bridge, dormant (not promoted). This note records the
verdict and the corrected science so the lead is not re-walked. Moved from
`notes/unsorted/` (the seed draft) on park.*

---

## What was proposed

Harvest the OML-descent park (the lone open problem, itself parked) into a contribution.
Claimed **Type 5 (impossibility-sharpening, primary) + Type 6 (exposition, secondary)**.
Central thesis — the **"Boolean-factoring claim":** for a concrete σ-complete OML `L`,
any large-cardinal / set-theoretic strength in the *existence* of a σ-additive
dispersion-free (2-valued) state on `L` factors through a Boolean sub-object; the
non-distributive part only *carries* strength, never *generates* it. A σ-essential
witness would be exactly a counterexample. Evidence offered: Blecher–Weaver 2017
(claimed positive instance — strength factors through the diagonal masa), Bunce–Wright +
Koszmider (contrast "free" instances).

## Why it parked — the audit kill (Phase 2, `/audit full`, opus, web-search)

**PRIMARY-SOURCE KILL. The flagship evidence was misread, and read correctly it
*refutes* the thesis.** Blecher–Weaver (arXiv:1607.08505, JFA 272 2017, proof read
verbatim pp.1–9) splits two ways:
- **Real-valued (non-pure) dichotomy (Thm 3.1/3.3):** strength DOES factor through the
  diagonal masa `ℓ∞(κ)` via conditional expectation `φ∘E`. Masa-factoring holds here —
  but this is NOT the 2-valued dispersion-free object.
- **Pure / 2-valued dichotomy (Thm 2.4(ii),(iv)) — the σ-essential object:**
  masa-factoring **FAILS**. B–W §4 (p.6): clean factoring "would be easy if **Anderson's
  conjecture were true**... **the conjecture is known to be false**" (∞-dim `H`, CH).
  They invoke generalized **Kadison–Singer / Marcus–Spielman–Srivastava paving** —
  genuinely non-commutative — *because the pure state does not reduce to a masa*.
- **Direct counterexample: Akemann–Weaver, "B(H) has a pure state that is not
  multiplicative on any masa," PNAS 105(14) (2008) 5313** — a pure (2-valued) state
  factoring through NO abelian subalgebra. This *is* "set-theoretic strength on a
  non-Boolean structure not factoring through any Boolean sub-object."

**Type 5: FAIL** — on three independent kill tests:
1. **Tautology.** "σ-essential witness = counterexample to Boolean-factoring" just renames
   the contrapositive of the *definition* of σ-essential (contextuality carried by no
   Boolean/finite sub-object). No structural insight; the framework's named Type-5 failure
   mode ("rephrases an existing impossibility in different notation").
2. **Evidence inverts.** The one resolved non-Boolean instance (B(H), pure) is a
   *counterexample*, not a confirmation. A pattern that inverts on its strongest instance
   is a misread, not a mechanism.
3. **Not a sharpening of rem:dw.** The claimed "second cut" (B(H)) does not say
   "non-Boolean part is free"; it says the opposite. What remains is rem:dw (one cut,
   already recorded) + a now-contradicted conjecture.

**Where masa-factoring IS true (real-valued case), it is PRIOR ART:** Weaver, "Set theory
and C*-algebras" (arXiv:math/0604198); Farah, *Combinatorial Set Theory of C*-algebras*
(Springer 2019); Dzhenzher arXiv:2604.25854 (frames the full-`B(ℓ²(κ))` extension as an
OPEN problem). So even the true half is not novel.

**Type 6: CLEARS NARROWLY — but only as a corrected open-question bridge, and we are
NOT promoting it.** The cross-field gap is empirically real (audit verified
Burešová–Pták 2024 arXiv:2401.13798: all 15 refs Czech–Slovak quantum-logic school, ZERO
operator-algebra/set-theory refs; the B–W/Dzhenzher line cites no OML work). A short
expository note *could* clear Type 6 — but its content would have to be *"two communities
independently circled the same **open** question — does set-theoretic strength of
σ-additive 2-valued state existence ever genuinely need the non-distributive structure? —
and neither knows the other's results,"* with the thesis stated in the **correct**
direction (pure/2-valued non-commutative case is OPEN, masa-factoring fails there). It is
modest, venue-dependent (Expositiones Mathematicae / a quantum-structures venue), and the
researcher's call is **park, do not pursue now** (no publication pressure; the corrected
message is "this is open," which the existing survey + records already carry).

**Types 1/2/3/4/7: FAIL / not the real contribution** (no new/re-proved theorem; the
cross-field link is co-location not method-transfer — Type 3 fails as the sibling
"barycenter transfer" already did; "Boolean-factoring" renames a definition — Type 4
three-statements test fails; no method — Type 7 N/A).

## The record correction this audit forced (done 2026-06-23)

The session's earlier records asserted *"a measurable cardinal that bites WITHOUT
factoring through a Boolean sub-object was NOT FOUND"* and *"B–W STRENGTHENS rem:dw."*
**Both are FALSE** (Akemann–Weaver is exactly such an object). Corrected in:
`sigma_essential_prior_art_verdict.md` (2026-06-23 CORRECTION block),
`CHARTED_sigma_essential.md` (⚠⚠ retraction + FENCE), `program_overview.md` (S12–13
CORRECTION), and `MEMORY.md`. **`rem:dw` itself is UNAFFECTED** — it is the
Derr–Williamson Polish cut on concrete OMLs, not a claim about B(H) masa-factoring; only
the "B–W-strengthens-it" gloss was withdrawn. The CHARTED file's own standing ⚠ flag
("BW abelian-restriction phrasing INFERRED not verbatim") had correctly anticipated this.

## Lessons logged

- **Verify-by-reading-the-proof beats verify-by-abstract.** The deep-research sweep read
  abstracts + ar5iv HTML and the 2026 follow-ups' *gloss*; it did not read B–W's §4–5
  proof, where the pure-case non-factoring is explicit. The audit's verbatim read flipped
  the verdict. (Matches `feedback_verify_by_building` — catch wrong framings by reading the
  primary source.)
- **A "diagnosis" that is the contrapositive of a definition is a tautology, not a
  result.** Guard against renaming `σ-essential ≡ non-factoring` as a mechanism.
- The **park of the lone open problem still stands** — for the σ-LS-residue reason, NOT a
  Boolean-factoring one. This seed was an attempt to harvest a contribution from that park;
  it did not clear the bar. Honest stop. The genuinely-new-object door (option c) remains
  the only un-parker.

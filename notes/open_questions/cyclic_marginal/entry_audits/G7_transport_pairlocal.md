## 1. thm.transport_general

**Stripped statement.** Let C(β) be the Dynkin system on β³ generated by pair events (sets depending on
two coordinates). For coordinatewise maps f_i : α → β, write F = (f_0, f_1, f_2). Then
F⁻¹(C(β)) ⊆ C(α).

**Why it is known.** Preimage under a fixed map commutes with complement and disjoint union. So
{E : F⁻¹E ∈ C(α)} is a Dynkin system. It contains the generators, because a coordinatewise map pulls
pair events back to pair events. That is the textbook good-sets argument behind f⁻¹σ(G) = σ(f⁻¹G),
transposed verbatim to Dynkin systems. The Lean proof (`TransportGeneral.mem_pre`) is a six-line
induction, which confirms it is routine. Mathlib's σ-algebra analogue is
`MeasurableSpace.comap_generateFrom`. I did not look up the exact textbook lemma number (folklore).

- **Pure verdict:** KNOWN (folklore / textbook: good-sets argument, preimage commutes with generated
  Dynkin system).
- **Owner:** standard measure theory, under the name "preimage of a generated σ-algebra / Dynkin
  system"; σ-algebra form in every graduate text and in Mathlib. Read level: standard (argument
  reconstructed in full; no single source pinned).
- **Type 3:** FAIL. No method transfer; it is an infrastructure lemma.
- **Type 4:** FAIL. No new vocabulary.
- **Referee estimate:** REJECT-LIKELY as a standalone item. Venue: none. Value: none on its own
  (infrastructure). Main risk: "standard good-sets argument".
- **Keep it as:** a Lean infrastructure receipt. It matters to the programme because it carries the
  finite-quotient (mod n) witnesses and the pulled-back supplies. That is a role, not a claim.

**Proposed status line:**
`"LEAN-CHECKED 2026-10-21 (TransportGeneral.mem_pre; 0 sorry). OWNED (folklore): preimage commutes with generated Dynkin system (good-sets argument; sigma-algebra form = Mathlib MeasurableSpace.comap_generateFrom). Infrastructure, not a claim. Audit G7 2026-10-27."`

## 2. thm.problem3_pair_local

**Stripped statement.** On {0..n−1}³, let J be the Dynkin system generated by single-coordinate events
and comparison events {x_i < x_j}, {x_i = x_j}, {x_i > x_j}. For n ≥ 3, J = P₀₁ ∪ P₁₂ ∪ P₂₀, where P_e is
the Dynkin system on pair e generated by that pair's rows, columns and comparison classes. For n = 2,
J is the full carrier D. Consequence: every pairwise-consistent family of pair laws (strict
Condorcet cycle included) is a state on J.

### Owners found

**(a) Dravecký–Šipoš 1980, Example 6: the mechanism.** Primary source, full text read again for this
audit, pp. 301–302.
- Statement: if f + g takes two values, and nonempty preimage sets from A_f, A_g, A_{f+g} pairwise
  meet (condition (2)), then C = A_f ∪ A_g ∪ A_{f+g} is a σ-class.
- Proof: a disjoint family must lie in a single A_h.
- Problem 3's theorem uses exactly this argument: "U = ⋃ P_e is closed under complement; disjoint
  nonempty members of different blocks are impossible, hence U is closed under disjoint union".
- §14 and §20 of `definitions_draft.md` already credit it ("a D–Š-type mechanism, but relative to
  pairs").
- **Generalisation is small.** The blocks are Dynkin systems P_e rather than σ-algebras A_h. Condition
  (2) holds only off the shared-variable sub-algebra: cross-pair members may be disjoint when one
  depends only on the shared variable, and then it lies in both blocks. "Union is closed unless
  disjoint cross members exist outside the common part" is the same one-line argument.

**(b) Gudder 1969, Neubrunn 1970, Katriňák–Neubrunn 1973: neighbours.**
- These works characterise when a σ-class (or the class generated by A) is a σ-field, and when a
  family of sub-σ-fields sits inside a common sub-σ-field. Katriňák–Neubrunn Lemma 2 and Thm 2 were
  read in full; Neubrunn 1970 was read at abstract level only (AMS 403).
- They concern compatibility, i.e. intersections lying in C, not unions of blocks being closed. They
  do not own the union-class step; D–Š does.

**(c) Social choice: owns the "reading", and partly contradicts the one-line gloss.**
- **Block–Marschak 1960, Guilbaud 1953, Fishburn 1992.**
  - Pairwise binary-choice probabilities come from a distribution on rankings iff they lie in the
    linear ordering polytope.
  - For three alternatives, the cyclic triangle inequality P(a>b) + P(b>c) + P(c>a) ≤ 2 is a facet.
    Verify the facet claim in Fishburn 1992 or Doignon–Fiorini–Joret before citing it as such.
  - The strict Condorcet cycle (sum 3) violates it.
  - Read level: search and snippet. Fishburn 1992 is "a status report", Math. Soc. Sci. 23, 67–80.
- **HodgeRank (Jiang–Lim–Yao–Ye 2011, shelf, abstract).** Cycles ARE visible from pairwise comparison
  flows, as curl or harmonic components.
- **Consequence for scope.** "Comparisons cannot detect Condorcet cycles" is FALSE as a general claim.
  Linear checks that combine pairs (the triangle inequality, curl) see the cycle.
  - What Problem 3 proves is narrower: no single *question* (set) built from comparisons and values
    by "not" and "either one" crosses pairs.
  - The detecting inequality corresponds to the indicator identity
    1{x₀<x₁} + 1{x₁<x₂} + 1{x₂<x₀} ≤ 2 (no strict cycle). That is a non-disjoint cover, so it is not
    expressible in J.
- **This contrast is the item's real content.** Dynkin closure (states = additive only on disjoint
  unions) cannot express the facet that social choice uses. It should be stated, with the owners,
  wherever the Condorcet reading appears.
- **Saari.** Owns "pairwise tallies lose information (the Condorcet component)" in words, not this
  statement. Read level: search.

**(d) Combinatorial residual: not found, judged routine.**
- Residual 1 is the normal form P_e ⊆ {K Δ R_α Δ C_β}, Lemma 1. It is Lean-checked as
  `PairNormalForm.closure_le_NF`, so the taxonomy's "Lemma 1 hand" is now stale.
- Residual 2 is "at most one empty row/column" for n ≥ 3, Lemma 2, Lean-checked as
  `indep_of_two_empty_rows`.
- Both are elementary: threshold sets of distinct thresholds cannot coincide. An expert would call the
  combination a routine verification that the D–Š condition holds relative to the shared variable.
- No source states this instance. None was found for:
  - Dynkin or σ-classes generated by comparison events;
  - pasting of three pair-blocks along shared one-variable algebras;
  - the n = 2 exception (J = D).
- Searches in the concrete-logic / OML pasting literature (Navara–Tkadlec blocks, pasting) found the
  framework (a concrete logic is the union of its blocks) but not this instance.

**Hand check of the assembly (done for this audit, ⟦HAND⟧).**
- Case "A depends only on its non-shared variable": A and B depend on disjoint coordinate sets, so
  they meet. Correct.
- Multi-piece unions: absorb pieces sequentially, using the pairwise lemma on (A₁ ∪ … ∪ A_k, A_{k+1}).
  Correct, since the lemma covers any two disjoint members of U.
- Lemma 2 with K ∈ {∅, X²}: an empty row forces β trivial, so the set depends on x only. Correct.
- No gap found. Countable unions on a finite Ω reduce to finite ones.

### Verdicts

- **Pure verdict: PARTLY OWNED.**
  - The mechanism (union of blocks is a σ-class when cross members meet) is owned by Dravecký–Šipoš
    1980 Ex. 6, primary source read.
  - The consequence that pairwise-consistent comparison families incl. Condorcet cycles exist and are
    detected only by cross-pair linear facets is owned by Block–Marschak / Fishburn (snippet level)
    and HodgeRank (abstract).
  - Residual: the instance check (Lemmas 1–2, n ≥ 3, n = 2 exception). It is not found in print but is
    elementary, and an expert would call it routine.
  - Not NOVEL under the cap: the nearest work for the residual (Neubrunn 1970) is unread past the
    abstract, and the residual is in any case routine.
- **Type 3 (method transfer):** FAIL as an item. D–Š's union-class argument is transferred from
  σ-algebras of single functions to pair Dynkin systems, but within one field (concrete logics), by the
  same proof. That is reuse, not transfer between domains.
  - **Candidate transfer, not demonstrated.** The facet-vs-Dynkin contrast could carry social-choice
    facets (linear ordering polytope) into a test of which question algebras see them. Nothing here
    does that yet.
- **Type 4 (three statements + one non-trivial result):** FAIL. "Pair-local" is the D–Š union class
  relative to pairs. Only one statement is new in that vocabulary (J = ⋃ P_e for n ≥ 3; J = D at
  n = 2), and its proof is routine.
- **Referee estimate:** REJECT-LIKELY as a standalone result. It would be acceptable as a lemma or
  remark inside the note.
  - Venue class: none standalone (lemma in an expository note).
  - Value carried by: none standalone; factor 4 inside the note (organising the Condorcet contrast).
  - Main risk a referee would raise: "this is Dravecký–Šipoš Ex. 6 applied to pair blocks; and
    comparisons do detect Condorcet cycles (triangle facet, HodgeRank). State that the blindness is
    only for disjoint-union-built questions."
  - Pure verdict is not UNCLEAR on the mechanism, so the BORDERLINE cap does not bind; ownership of
    the main mechanism drives REJECT-LIKELY.

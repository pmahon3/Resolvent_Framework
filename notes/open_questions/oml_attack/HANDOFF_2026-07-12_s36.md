For the 7-loop removable face `C={a0,a3,a11}`, session 36 exhausts every
period-one oriented injective width-four atom port and combines this with
the s35 width-1/2/3 census.

Width four has `C(14,4)^2 4! = 24,048,024` labeled ports.  A pair-distance
prefilter retains 477,848; the exact two-cell quotient-incidence test

For cluster-stabilizer target representatives `a1,a2,a4`, the full

1. target `a1`, port `((0,11),(3,5),(6,9),(13,3))`;
2. target `a1`, port `((1,7),(5,9),(11,11),(12,3))`.

Both have relay girth five through 120 cells and adjacent target distance

nonorder in each.  A self-contained oracle gives an even earlier rooted-
cell kill: candidate 1 misses `a0 !<= a4` in cell 0 and candidate 2 misses
`a0 !<= a10` in cell 0 among all exactly-one-master paths.

This exposes an important screen distinction.  The phase `live` mask is
an **any-position union**: it can order-determine the repeated cell type
without order-determining the actual boundary cell 0.  Root-cell order
determination by `E1[0]` (and then fixed-offset separation) is a required
downstream gate.  There is no contradiction between the local screen and
the global kill.

Verdict: rigorous bounded no-go for this face, period one, all injective
ports of widths `k<=4`.

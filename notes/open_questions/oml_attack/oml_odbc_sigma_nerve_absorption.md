## 1. Index-category fence on closure-based globalization (the keeper)

Any future argument that σ-lattice closure forces globalization
(CODBC-shaped: "closure enriches the bonding system until sections
glue") via a Mittag–Leffler-type condition is valid **only over
countably cofinal index systems**. Over `[ω₁]^{≤ω}`-shaped posets —
where `𝒥_{≤ω}(I)` lives for uncountable atlases — surjective bonding
does not kill the derived limit, and the correct obstruction object is
limⁿ (higher derived limits), not lim¹. **Standing fence:** a
closure-based CODBC proof must either exhibit countably cofinal
reduction for its specific system or use general-index-poset
derived-limit technology. ⟦Certified correct by the Phase-2 audit⟧

## 2. Obstruction-shape restatement (recorded to prevent re-derivation)

## 3. Binary regularity (dormant definition)

An interface is binary-regular when every eligible interface state has
exactly two lifts into each adjacent block; on a two-element fibre the
swap involution is canonical, so no "definable involution" datum is
needed. A decision atlas has all fibres binary-regular. Status: **no
σ-scale instance exists in the corpus** (zoo typing, seed §6), and no
architecture has been designed for it. Recorded in case one appears;
carries no claim.

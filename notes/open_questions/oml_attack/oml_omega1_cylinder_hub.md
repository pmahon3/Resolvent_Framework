# The omega-one cylinder hub and incompatible activation

*Campaign 12, 2026-07-14. Countably generated quotient boundaries cannot
delete hub sigma-states. An uncountably generated cylinder boundary gives an
exact Boolean CSS-without-GS atlas in ZFC, but its common copy is central and
is not an admissible OML counterexample.*

## 1. Countably generated extension theorem

Let `A` be a countably generated Boolean sigma-algebra and
`j:A -> L` a faithful sigma-homomorphism into a sigma-complete OML whose
sigma-additive two-valued states separate order. Then every sigma-additive
two-valued state on `A` extends to one on `L`.

*Proof.* Choose generators `(a_n)`. For a sigma-state `mu`, let `b_n=a_n`
when `mu(a_n)=1` and `b_n=a_n^perp` otherwise. The decreasing finite
conjunctions all have value one, so countable additivity gives

\[
 c_\mu=\bigwedge_n b_n,\qquad \mu(c_\mu)=1.
\]

Thus `c_mu` and its faithful image are nonzero. Order separation supplies a
global sigma-state charging `j(c_mu)`. It chooses every prescribed side
`j(b_n)` and hence agrees with `mu` on all generators and all of `A`.
**Evidence class: hand proved.**

The sigma-homomorphism and faithfulness hypotheses are load-bearing. A star
whose cells meet the hub only through such faithful countably generated
boundaries cannot delete a hub sigma-state: fix the state and extend it in
every cell. **Evidence class: hand proved.**

For a standard Borel hub, if countably many countably generated Borel
quotient algebras jointly separate points, their generated sigma-algebra is
countably generated and separating, hence is the full Borel algebra by the
Borel injection/Lusin--Souslin theorem. It contains all singletons and
recreates the puncture obstruction. **Evidence class: hand proved.**

## 2. The uncountably generated cylinder boundary

Let

\[
 I=\omega_1,\qquad H=2^I,
\]

and let `A` be the product sigma-algebra generated by the coordinate
cylinders. Every event in `A` depends on only countably many coordinates:
the countable-support events form a sigma-algebra containing the generators.
Conversely all coordinates together separate points.

Every sigma-additive two-valued state of `A` is evaluation at one point of
`H`. Its values on coordinate cylinders determine `x in H`. If an event
depends on the countable set `J`, the intersection of the chosen coordinate
sides over `J` has state value one and decides the event exactly as
evaluation at `x`. **Evidence class: hand proved.**

For `i in H`, put

\[
 G_i=H\setminus\{i\},\qquad B_i=P(G_i),
\]

and define `j_i(E)=E intersect G_i`. This is an injective sigma-homomorphism:
any nonempty countable-support event contains points differing outside its
support and cannot be the singleton `{i}`. **Evidence class: hand proved.**

## 3. Local extension classification

For `x != i`, evaluation at `x` extends to the point state on `B_i`.
Evaluation at `i` has a finitely additive extension: its trace filter

\[
 \{E\setminus\{i\}: i\in E\in A\}
\]

is proper, since every finite intersection leaves coordinates outside a
countable support free. The Boolean ultrafilter lemma extends it to
`P(G_i)`. **Evidence class: hand proved**, using the Boolean ultrafilter
lemma.

There is no sigma-additive extension of evaluation at `i`. Partition `G_i`
by

\[
 D_\alpha=\{x:\alpha\text{ is the least coordinate with }x_\alpha\ne
 i_\alpha\},\qquad \alpha<\omega_1.
\]

A sigma extension is a countably complete ultrafilter on `G_i`. Pushing it
forward by the least-difference map gives a countably complete ultrafilter
on `omega_1`. It is nonprincipal: every singleton fibre `D_alpha` is
contained in a coordinate-difference cylinder rejected by the extension.
This contradicts Ulam's ZFC theorem that `omega_1` carries no nonprincipal
countably complete ultrafilter. **Evidence class: hand proved**, importing
that recorded ZFC theorem.

## 4. Exact Boolean CSS/no-GS atlas

The common-boundary family `(B_i)_{i in H}` has:

- a compatible sigma-section over every countable `J subset H`, by choosing
  `x notin J` and point-evaluating in every `B_i`;
- no global compatible sigma-section, because every common `A` sigma-trace
  is evaluation at some `x`, which does not extend sigma-additively to
  `B_x`;
- an atlas-compatible global finitely additive tuple for every chosen `x`,
  using point states off `B_x` and an ultrafilter extension in `B_x`.

**Evidence class: hand proved.** The last object is an atlas section, not a
global state of an OML.

This refutes any extension of the countably generated puncture theorem to
all separating sigma-boundaries. It is an exact central Boolean
CSS-without-GS realization, not an OMP, OML, or admissible counterexample.

## 5. Centrality gate

In the raw union of blocks all containing `A`, every displayed event commutes
with every `a in A`. The same remains true in the algebraic OML generated
using finite lattice and orthocomplement operations, because the commutant
of `a` is a sub-OML. Hence `A` is central in the raw atlas and its finite
algebraic OML closure. **Evidence class: hand proved.**

No sigma-closure claim follows. In a sigma-complete OML, an L-countable join
of commuting block elements can leave the block and need not continue to
commute with `a`; maximal blocks themselves need not be sigma-complete.
Thus a sigma-completion could in principle de-centralize `A`, but every new
countable join, maximal block, and state relation would then require audit.
**Evidence class: open** for such a completion.

## 6. State-coordinate rigidity

Let `St_sigma(L)` separate order. If two events have equal values in every
sigma-state, they are equal: otherwise order separation witnesses one failed
order direction. If `c` commutes with `a,b` and every sigma-state charging
`c` gives `a,b` equal values, then

\[
 c\wedge a=c\wedge b.
\]

States killing `c` kill both compatible meets; states charging `c` evaluate
the meets as `a,b`; separation finishes. Thus conditionally equal faithful
boundary embeddings reconstruct a literal common cut on any compatible
activation face. **Evidence class: hand proved.**

A distinct-support star can escape this only through an incompatible
activation cylinder not represented by one event, collapsing quotient cut
maps, MBRC failure/additional states, or failure of an admissibility
hypothesis. Conditional state relations alone do not specify carrier
embeddings or a canonical completion. **Evidence class: hand proved.**

## 7. Incompatible activation control

In the horizontal sum `H_4` of four four-element Boolean algebras, sigma
states are all independent four-bit assignments, separate order, and the
centre is `{0,1}`. The incompatible finite pattern

\[
 \mu(a_1)=\mu(a_2)=\mu(a_3)=1
\]

has two states but is not the support of any event: every nontrivial event
has eight supporting states. Hence finite-pattern activation plus order
separation does not force a single activation event. **Evidence class: hand
proved.**

For already-global states satisfying a finite pattern `P`, three activated
pairwise diagonal constraints imply

\[
 (\mu(q_1),\mu(q_2),\mu(q_3))\in\{000,111\}.
\]

If both values occur, the relation is exactly the triple diagonal. This is
only transitivity on existing global states; it proves neither gluing nor
MBRC. **Evidence class: hand proved.**

## 8. Exact residue

Countably generated faithful quotient boundaries cannot implement puncture
deletion. The omega-one cylinder atlas implements the desired CSS/no-GS
semantics but is central in its raw and finite algebraic closures. A live
construction may transport its uncountably many coordinate quotients through
conditional noncommuting cells, or attempt a sigma-completion whose new joins
de-centralize the common boundary, while the complete maximal-block inverse
limit still reconstructs one hub point.

The next exact test needs explicit incidence embeddings, not only a state
relation. Its gates are:

1. incompatible finite activation remains nonempty after completion;
2. every countable transported subatlas admits one common point section;
3. the full atlas forces a single hub point and deletes it at its puncture;
4. mixed and sigma cuts either avoid a commuting common `A` or explicitly
   de-centralize it without corrupting the intended relations;
5. MBRC holds over every new maximal block;
6. centre and order-separation gates pass.

No finite census can certify the omega-one nonextension mechanism. A finite
three-cell control can test activation and pairwise/triple MBRC only after
literal carrier and embedding data are supplied.

# McDonald–Bimbó primeness: is the PR_dual ⟹ PR_lattice nesting free?

Audit gate for the "two grades of probabilistic realism" claim. The note
asserted PR_dual ⊊ PR_lattice as a strict NESTED stratification, treating
the easy direction PR_dual ⟹ PR_lattice as free via "restrict μ̂ to the
⊥-stable clopens." The audit flagged this as NEEDS-EXTRA-HYPOTHESIS. This
note settles it from the primary source.

**Source:** McDonald & Bimbó, "Topological duality for orthomodular
lattices," `notes/literature_review/literature/mcdonald_bimbo_2023.pdf`
(Math. Log. Quarterly 69 (2023) 174–191; arXiv:2208.07430). Read directly,
not from recall.

## The decisive question

PR_lattice requires s to be σ-additive ON THE LATTICE: s(⋁ₙaₙ) = Σₙs(aₙ)
for orthogonal aₙ. Restriction of a dual measure μ̂ recovers only FINITE
orthoadditivity. The gap is μ̂(D), D = h(⋁ₙaₙ) ∖ ⋃ₙh(aₙ). PR_dual ⟹
PR_lattice is free IFF concentration on P(A) forces μ̂(D) = 0 — i.e. iff
D ∩ P(A) is empty, i.e. iff principal filters are σ-PRIME (a principal
filter containing ⋁ₙaₙ must contain some aₙ).

## What McDonald–Bimbó actually says (verbatim points)

1. **P(A) = principal filters.** "for any element a ∈ A, its principal
   upset ↑a is a filter, known as the principal filter generated by a"
   (p. ~6); S₀(A) carries "a distinguished subset P(A) ⊆ F(A) of principal
   filters" (abstract). NB the audit said "prime"; the actual object is
   PRINCIPAL — the argument is unchanged but the terminology is principal.

2. **A filter is "non-empty and possibly improper" — NO σ-condition.**
   The definition imposes upward closure + meet-closure only. There is no
   σ-prime, σ-complete, or countable-join hypothesis on filters anywhere.

3. **The "completeness" mentions in the paper are unrelated:** they are
   either (a) soundness/COMPLETENESS of the quantum logic Q, or (b)
   "⟨F(A), ⊆⟩ is a complete lattice" — automatic for the filter lattice,
   NOT a hypothesis on A or its filters.

4. **Finite ⟹ every filter principal** ("in a finite lattice A every
   filter x ⊆ A is principal"). This is exactly why the finite MO₂ test
   (`pr_dual_inhabitation.py`) had no descent content — confirmed from
   source.

5. **The duality is finitary:** CO(S₀(A))† is closed under ∩ and ⊥ only;
   the OML join is the biorthogonal closure (⋃h(aₙ))^⊥⊥, not set-union.

## Verdict: nesting is NOT free

Principal filters are NOT σ-prime. Concrete witness in C(H) = L(H):
let aₙ = span(eₙ) (orthonormal basis), p = span(v) for v of infinite
support. Then p ≤ ⋁ₙaₙ = H, so ↑p ∋ ⋁ₙaₙ; but p ≰ aₙ for every n, so
↑p ∌ aₙ. Hence ↑p ∈ D ∩ P(A): the defect set contains principal filters.
A measure concentrating on P(A) can put mass on ↑p, so μ̂(D) need not be 0.

Therefore **PR_dual ⟹ PR_lattice is NOT free** — it requires an extra
σ-continuity hypothesis (μ̂ null on countable-join defects D) that the
finitary 2023 duality does not supply. The audit's escape route ("if MB
primeness were secretly σ-prime the nesting would stand") is CLOSED: MB
filters carry no σ-condition.

## Consequence for the note

- "PR_dual ⊊ PR_lattice, strict witnessed stratification" is WRONG as a
  nesting claim. Correct: a **witnessed one-directional SEPARATION**
  (L(H) normal states clear PR_lattice via Gleason, fail PR_dual via #1);
  the reverse inclusion is CONDITIONAL on a σ-continuity hypothesis the
  duality does not supply — not a proven nesting.
- This is fully consistent with the note's own finitary-wall claim (#2):
  the same failure of h to preserve countable joins that blocks
  statability of descent also blocks the free nesting. The note was
  internally inconsistent in writing ⊆ as if the wall were closed; the
  reword removes that inconsistency.
- Also confirmed (audit point 1): the #1 clustering kill needs only
  finitely many ⊥-stable clopens, so it does NOT depend on any
  full-clopen / P(A)-measurability detour. That justification in the note
  is over-engineered and should be simplified.

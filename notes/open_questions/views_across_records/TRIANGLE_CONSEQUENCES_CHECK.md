## C2. "Box set on a finite grid" = "0/1 vector of V₀₁"; so D = V₀₁∩{0,1}^Ω at every size

**(a) Box ⟺ span ⟦HAND⟧.** Lean `Box`: f(a,b,c)+f(a′,b′,c)+f(a′,b,c′)+f(a,b′,c′) = f(a′,b,c)+f(a,b′,c)+f(a,b,c′)+f(a′,b′,c′).
- Span ⇒ Box: a function of (x₀,x₁) contributes g(a,b)+g(a′,b′)+g(a′,b)+g(a,b′) to both sides; same for the other pairs.
- Box ⇒ span: fix (a′,b′,c′). Then f(a,b,c) = f(a′,b,c)+f(a,b′,c)+f(a,b,c′) − f(a′,b′,c) − f(a′,b,c′) − f(a,b′,c′) + f(a′,b′,c′):
  seven terms, each a function of at most two coordinates, with the values of f as coefficients.
- So for a 0/1 vector the pair-sum is automatically integer, and ℤ, ℚ, ℝ give the same class. Any grid, finite or not.
  Hence B (box sets) = V₀₁ (0/1 vectors in the span of pair-cell indicators). Gate file §2 already says "B = {E : Box(E)},
  the sets whose indicator is a sum of pair functions".

## C1b. Real-valued states are determined by their window marginals

**Verdict: TRUE** (given D₃ = D_fin). Hypotheses: s, t : D₃ → ℝ (any abelian group), each additive on disjoint pairs of
carrier sets, equal on window events. No positivity, boundedness or normalisation is needed: Ω is a window event, so
s(Eᶜ) = s(Ω) − s(E) follows. Lean `agree_of_dfin` is typed for ℤ, but its proof is three rewrites along `Dfin`
(`basic`, `compl`, `union`) and uses nothing about the codomain; the ℝ version is not in Lean. Scope: uniqueness only.
Which marginal families occur is the positivity question of C2(d). On finite grids this is the trivial induction; the
content is the infinite case.

## C6. A compatible family extends iff Λ is {0,1}-valued on D₃, uniquely

**Verdict: TRUE; and the condition always holds (new, ⟦HAND — this agent only, unverified⟧).**
- Λ_u(F) := u₀₁(f₀₁)+u₁₂(f₁₂)+u₂₀(f₂₀) for 1_F = f₀₁+f₁₂+f₂₀ (seven-term formula; finitely valued). Well defined for
  matching marginals (reversal check, final inference; re-derived). Λ is linear with Λ(Ω) = 1, so on D₃ it is additive
  automatically. ⇐: if {0,1}-valued there, it is a state with family u. ⇒ and uniqueness: any state with family u equals
  Λ_u on D_fin = D₃. The domain must be D₃ (= box sets with no infinite K-clique), not all box sets: Λ(E*) = 2 for the
  staircase family, which does extend.
- **Always {0,1}.** Normal form F = W₀₁ ⊔ W₁₂ ⊔ W₂₀ ⊔ g⁻¹(F̂). Λ(g⁻¹F̂) = [g(p) ∈ F̂] (gate file §5c), with p the marginals.
  Two W's cannot both have value 1: disjoint events A×X₂ and X₀×B share no x₁-value, and π₁(A), π₁(B) would both be in p₁.
  A W and the pullback cannot both: if g(p) = c ∈ F̂, the cell C₀×C₁×C₂ = g⁻¹(c) ⊆ F has C₀×C₁ ∈ u₀₁, so it meets A.
  Hence Λ_u(F) ∈ {0,1} for every F ∈ D₃ and every compatible family.
- **Effect on `conj.triangle_extends_all`** (`glued_carriers_taxonomy.json:488–491`: "Every family of window ultrafilters
  on the triangle with consistent marginals extends to a state on D3 …"; status "open; TRUE for all 27 tensor-type

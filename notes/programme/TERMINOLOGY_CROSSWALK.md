# Terminology crosswalk: internal words vs established terms

reviewed: false. 2026-11-06. Read-only audit. No other file was edited. Nothing is renamed by this note.

**Method.** The scope is the tracked files (`git ls-files`, 1614 files), filtered to `*.md`, `*.tex`, `*.json` and `*.lean`. Counts come from Python regexes and are **approximate**.
- `hum`: human-written md, tex and taxonomy json, excluding any path containing `/archive/`.
- `mach`: machine output, kept out of the edit batches (`deep_research_*.json`, `verification/*.json`, receipts, `*_schema.json`, `full_grid*`, `SHELF_INDEX.json`).
- `arch`: any `/archive/` path. These are counted but never edited.
- `Lc` / `Li`: Lean hits in comments and docstrings / in code and identifiers. Identifiers are frozen.
- "papers" means `papers/*/*.tex` only. The notes `.tex` (`pointless_coherence.tex`, `order_without_a_centre.tex`, the kits) count as `hum`, and their edits need approval. The blueprint `formalization/QuerySystem/blueprint/src/content.tex` carries `\lean{}` tags, so it is treated like Lean: prose glosses only.
- Generic words (state, point, fibre, wall, Φ, descent, Gate) are counted only where the coined sense could be isolated. Otherwise the count is "n/a".

**Count caveat.** `centre/center` also matches LaTeX `\begin{center}`/`\end{center}`: 26 of pointless_coherence.tex's 27 hits and 2 of sigma_essential_body's 19.

**Citations.** `[shelf]` = in `SHELF_INDEX.json`. `[tax]` = a `*_taxonomy.json` owned region (id given). `[file]` = a repo prior-art or audit file. `[mem]` = from the auditor's memory, unverified: check before citing.

**Recommendations.**
- **REPLACE**: use the established term in new text, and in old text when it is next edited.
- **GLOSS**: keep the word; on first use in each document add the established term and the credit.
- **KEEP**: the word is programme-specific, with the reason given.
- **RETIRE**: obsolete.
- `(approval)`: the word was adopted deliberately by the user, so any change needs the user's yes.

#### A″. Notation for scenarios (adopted 2026-11-13; notes and prose only, Lean names stay frozen)

A **scenario** is a shape together with sizes, written **G(n)**. "Scenario" is the contextuality term (measurement
scenario, Abramsky–Brandenburger 2011); the bracket form for shapes is the statisticians' generator notation for
hierarchical models (Bishop–Fienberg–Holland 1975 [mem]).

| Write | Means |
|---|---|
| G | the **shape**: which groups of quantities are seen together. For pair observers, the standard graph names, alphanumeric only: **K₃** (triangle, all three pairs), **C₄** (4-cycle: neighbouring pairs of four), **K₄⁻** (K₄ minus an edge, the diamond graph: a 4-cycle with one diagonal), **P₄** (path: four in a line), **K₄** (four, every pair); in general K_m, C_L, P_m. Any other shape, including observers of three or more quantities, in brackets: [01][12][23], [012][23]. **No glyphs**: a triangle, box or lozenge symbol must not be used for a shape, since the box and the lozenge are the modal operators (necessity, possibility) (decided with the author 2026-11-13). |
| n = (n₀, …, n_m) | the **sizes**: quantity i takes nᵢ values. One number if all equal: K₃(3), K₄(2). ℕ for all natural numbers: K₃(ℕ). |
| G(n) | the scenario, e.g. K₃(3,4,4), K₄(3,3,4,4), C₄(2). |
| Ω(S) | the worlds of S (the grid); \|Ω\| = n₀·n₁·…·n_m. |
| V(S), V₀₁(S) | the span of the window indicators; its 0/1 members = the questions that **add up** (existing usage in `definitions_draft.md`, kept). |
| D(S) | the questions that can be **built** (the carrier); D_fin(S) the finitely built ones. Always D(S) ⊆ V₀₁(S). |
| Irr(S) | the **irreducible** members of V₀₁(S): every quantity has ≥ 2 values and no two values of any quantity differ simply. |
| St(S) | the **two-valued** answer patterns on D(S), with the product topology: the Stone-type space of the carrier. When D(S) is a Boolean algebra this is its Stone space in the usual sense, so the symbol keeps its conventional meaning (decided with the author 2026-11-13). Cf. `stone_role_prior_art.md`; Gudder's representation (Pták–Pulmannová 1991 Thm 2.2.1). |
| Pr(S) | **all** answer patterns on D(S), probability-valued included: a compact convex set. St(S) lies among its extreme points; on a Boolean algebra the extreme points are exactly St(S), on our carriers there can be extreme points outside St(S) (e.g. the hidden state on K₃(3,4,4)). Quantum-logic literature writes S(L) and S₂(L); avoided here because S names a scenario. |
| coarsening n → n′ | merging values; questions pull back along it (D and V₀₁ are preserved). |
| G′ ⊆ G | forgetting observers; D(G′(n)) ⊆ D(G(n)). |

Lean: `D₃` is D(K₃(ℕ)); `Dfin` is D_fin(K₃(ℕ)); `Box` is membership in V₀₁(K₃(ℕ)) (Kellerer's criterion).

## 2. Conflicts (same word, different meanings)

1. **C1 query (granularity note, not an error).**
   - Lean `structure Query` (QuerySystem.lean:97) is any measurable outcome type. `delayQuery` (DelayEmbedding.lean:100) has a d-tuple outcome, so the oldest layer already treats a multi-coordinate window as one query. The CLAUDE.md / theory_shape gloss "window = query" is consistent with it.
   - The nuance: Lean has no Abramsky–Brandenburger split between *measurement* (one variable) and *context* (a jointly measured set). In AB terms a repo query is a context, not a measurement.
   - The "measurement" translation in CLAUDE.md is therefore loose. Optional gloss: "query (= context; AB's 'measurement' is one coordinate)" (approval).
2. **C2 centre.** At least five senses:
   - (a) the OML lattice centre: "centre-free", `Centre`, `ring4_centre_trivial`, sigma_essential_body 19 hits; about 282 hits, almost all in the OML campaign;
   - (b) a common cause or shared driver (views_across_records);
   - (c) WHY's "order without a centre" (no coordinator);
   - (d) the centre of a frame (GPS, Earth-centred; order_without_a_centre.tex l.332);
   - (e) the Gibbs "centre at infinity" [tax R-gibbs-centre-at-infinity].
   - The worst collision: "centre-free OML" (irreducible) and "centre-free order" (no common cause) say opposite-flavoured things in the same repo.
   - Fix: OML notes say "irreducible"; synchrony formal text says "common cause".
3. **C3 reach.**
   - (a) `lem:reach`, the open core of the reconstruction paper (digraph reachability; Lean `Reach`, `reach_iff_walk`);
   - (b) the "reach" of a centre = cause arity m (FW_m, "reach ≥ 4", SOURCE_REACH_SCOUT);
   - (c) everyday "in reach".
   - Fix: rename (b) to "cause arity" / "factor width".
4. **C4 twist.**
   - (a) gluing obstruction (glued carriers);
   - (b) the OML W_P "twist count" = forced perspectivity bridges (W_P_TWIST_COUNT_EXPERIMENT, W_P_FEASIBILITY_LADDER);
   - (c) WHY_SIDECAR's "three practical forms of twist" (frustration, …), which is a lens;
   - (d) Lean "tensor-type / graph-type twist" (sub-kinds of (a)).
5. **C5 flat.**
   - (a) a window family that glues;
   - (b) "flat habitat" (psi_lat_attack_surface);
   - (c) "memory is flat" (OML engineering).
   - Separately, differential-geometry *flat* permits nontrivial holonomy round non-contractible loops, so sense (a) reverses the standard reading on cycles.
6. **C6 carrier.**
   - (a) the glued carrier D (a Dynkin closure);
   - (b) the OML-campaign carrier (`IsConcreteCarrier`, `isSigmaCompleteCarrier`), a concrete σ-complete OML;
   - (c) Product Ulam Carrier;
   - (d) "carrier" of a measure, i.e. its support (standard in Bhaskara Rao, Bourbaki) [mem];
   - (e) the Mathlib-style `.carrier` (the underlying set) in the Lean code.
   - (a) and (b) are compatible (both concrete logics). (d) is a real clash for measure theorists.
7. **C7 Φ.** OML Φ-forms (`PsiOML`, "Φ-primary", "Phi-tame") vs the closure phase Φ(w) (O-loopphase).
8. **C8 point.** Dirac state vs an element of Ω ("49730 points", "4-point fibre") vs Polish point. The trichotomy wording is safe only when "point" means "state".
9. **C9 window.**
   - (a) a two-coordinate context (glued carriers);
   - (b) a sliding length-L window on a symbolic orbit (reconstruction.tex, reconstruction_skeleton.tex, reading notes), i.e. a cylinder / block;
   - (c) a delay-embedding window (DelayEmbedding.lean, collision_vs_generation).
   - (b) and (c) are related to each other but not to (a)'s arbitrary pair events.
10. **C10 pointless.**
    - The repo: no two-valued (ultrafilter) extension to 2^Ω.
    - Pointless topology (locales) means "frames without points". Readers from Stone duality will assume the latter, and the answers-first stance makes that reading plausible.
    - On infinite Ω, Pták's "free" (non-Dirac) is NOT the same as pointless: it also covers ideal points. On finite Ω there are no ideal points, so free = pointless there.
    - DNP's "non-extendable" is stronger: it rules out every [0,1]-valued or signed extension.
11. **C11 commensurable.** QM "commensurable observables" = jointly measurable, a property of a pair of observables. Reconstruction "commensurable protocol" = C = R, a property of a scenario plus a coherence notion.
12. **C12 ceiling.** Gisin/Kela network bounds vs OML "block ceiling" / "rectangular-ceiling" / `least_interface_ceiling` (lattice upper bounds, computational projections).
13. **C13 frustrated (sign inversion).**
    - The repo calls a triangle with sign product +1 "frustrated" and one with product −1 "antibalanced".
    - Harary/physics call product −1 *frustrated* (unbalanced).
    - So every repo sentence "a centre can be revealed only on frustrated cycles" reads backwards to a signed-graph reader.
    - The prior-art file computes on −A (HYPERGRAPH_CENTRES_PRIOR_ART), which is consistent internally.
    - A third sense: "frustrating object" (commensurability seed = obstruction cycle), and SYNTHETIC_GATE's "frustrated" network regime (coupling type).
14. **C14 V_G vs V₂.** One quantity under two names: the per-edge split V_G (GAUSSIAN_PAIRWISE_MODEL:9) equals ρ(\|R−I\|) − 1 = V₂, proved in COVARIANCE_CEILING_CHECK.md l.12–14 via Elsner–Johnson–Dias da Silva 1988. Unify the names (approval).
15. **C15 fibre.** ρ⁻¹(x) (convex gluing) vs the σ-essential "4-point fibre" (a finite gadget) vs the OML "macrofibre" (decision-diagram slice). These are internal; flag only when they appear together.

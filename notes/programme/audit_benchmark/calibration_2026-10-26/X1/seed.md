# Seed

We use the Rasiowa-Sikorski lemma on generic filters for countable Boolean algebras to build a model of Peano arithmetic from forcing-style conditions. We show that in the resulting standard model the twin prime conjecture holds, i.e. there are infinitely many primes p with p+2 prime. The argument assigns to each arithmetic sentence a Boolean value and uses a countable family of dense sets to force the statement. A companion paper uses the same method to show infinitely many Mersenne primes.

# Seed

Hajnal's 1965 theorem says that in a graph whose largest clique has more than half the vertices, all maximum cliques share a common vertex. A conjectured analogue for k-uniform hypergraphs has a different threshold. We disprove it strongly: for every constant c<1 and uniformity at least 3 we construct hypergraphs with maximum cliques of size more than c times the number of vertices that cannot be pierced by any bounded set of vertices. Hence no universal threshold exists. We also pose related questions and a geometric variant using Helly-type arguments.

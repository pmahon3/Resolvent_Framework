# Seed: countable additivity is not first-order axiomatizable

**Claim.** Consider structures (𝔉, μ) where 𝔉 is a field of subsets of a set and μ : 𝔉 → [0,1] is
a finitely additive probability, in a two-sorted first-order language with the real field as the
second sort (or a fixed language for probability structures). The class of such structures in which
μ is σ-additive is not elementary: no first-order theory has exactly the σ-additive models.

**Proof idea.** Take a σ-additive model with infinitely many disjoint sets of positive measure
summing below 1 in a definable way, and pass to an ℵ₁-saturated elementary extension (ultrapower);
saturation produces a countable disjoint family whose measures do not sum correctly.

**Status of the question.** It does not appear to have been settled by an explicit proof in the
literature on probability logics.

**Declared types.** Type 1 (new theorem); Type 2 (new proof via saturation).
